Welcome to Nido's Coding Club! We are a student-led collective learning and creating things that can make a change through collaboration. The learning resources present on this page will always be present and available for everyone, including non-club members. These posts are **NOT** AI generated and will **ALWAYS** be human written to ensure you are not consuming, as they like to call it, *AI slop*. So if you see any imperfections in this or any writing, please excuse me (and let me know).

If you're new to clubs, we will meet on Fridays (TBD) afterschool unless explicitly announced otherwise. Attendence **will** be taken, and if you miss meetings for more than 3 times consecutively, we will need to talk to you asking in regards to your commitment to the club. Although this is not a high commitment club, Ms. Cope has established this recommendation for clubs to check up on those that miss meetings often.

In the first meeting, we will have a brief ice-breaker (TBD) and then we will jump into "*what is coding?*" and other topics we need to familiarize about. No coding will be done, however, we will attempt to set up your development environments on your devices. If you're reading this before the first/second meeting, you can check out the post [Setting Up Visual Studio Code](/post/setting-up-vscode) about setting up your development environment and [Installing Node.js](/post/installing-nodejs) about setting up your JavaScrit runtime.

Each week will have a designated post. To see what we'll do each week, please see [this post](/post/curriculum).
