Before we start, let's learn about comments. They're denoted by a double forward slash (`//`) and everything in the line after the double slash will NOT be executed as part of the code.

```ts
// this is a comment! it's greyed out.
```

## Data Types

Variables store data. They can store numbers, text, etc. And so you could conclude that there are different *types* of data.

Some of the primitive data types that we'll be using are:

---

* Numbers

```ts
let age: number = 17;
```

---

* Strings (text)

```ts
let surname: string = "Zhai";
```

---

* Booleans

```ts
let isStudent: boolean = true;
```

The colon (`:`) after the variable name tells you that the next part of the variable definition will tell you about its type.

You can also omit the type annotation (a.k.a. the colon and the data type), and make TypeScript *infer* the data type by checking "what's being assigned to this variable?"

## Arithmetic Operators

They do basic math! Here's a list:

```ts
let x = 10;
let y = 3;

console.log(x + y); // addition -> 13
console.log(x - y); // substraction -> 7
console.log(x * y); // multiplication -> 30
console.log(x / y); // division -> 3.333...
console.log(x % y); // modulus -> 1
```

You've most likely heard of the first 4, but what is a *modulus*?

The modulus operator divides the first term by the second and gives (returns) the remainder of that division.

For example, we have a pizza with 10 slices (`let x = 10`), divided beteen 2 people, and each person gets 3 slices (`let y = 3`). There has to be 1 (`x % y === 1`) slice leftover!

*What's that `===` you used?` - We're about to find out.

## Comparison Operators

There are a bunch of comparison operators.

```ts
let age = 17;

console.log(age > 13); // -> true; 17 is greater than 13
console.log(age < 13); // -> false; 17 is not less than 13

console.log(age === 17); // -> true; 17 equals 17
console.log(age === 13); // -> false; 17 does not equal 13

console.log(age !== 13); // -> true; 17 does not equal 13
console.log(age !== 17); // -> false; 17 does NOT not equal 17

console.log(age <= 17); // -> true; 17 is less OR equal than 17
console.log(age >= 18); // -> false; 17 is not greater OR equal than 17
```

Using a comparison operator **always** results in a boolean data type.

---

## Why `===` and not `==`?

You may have seen in other programming languages such as Java and C++ where comparison between numbers or even strings (in C++, not Java) use `==`.

Truth is, `==` exists in JavaScript, however, JavaScript does some funky stuff with types if the two types being compared aren't the same type, which can lead to some bugs and unexpected behavior.

One example of this is:

```ts
console.log("" == 0); // -> true
```

An empty string CLEARLY does not equal zero, they just both loosely equal false:

```ts
console.log(Boolean("")); // -> false
console.log(Boolean(0)); // -> false
```

Now, you may be wondering: what is `Boolean()`? And to that I say: we will soon be learning about functions!
