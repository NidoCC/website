## Anyway... why do we need a runtime?

A runtime is a layer that provides services to your code and a place for it to run. There are mutliple runtime environments, the most common one being your browser, which runs JavaScript code and parses HTML and CSS. As for JavaScript, there's Node.js, there's Deno, there's Bun, the two latter being way faster than Node.

So then, why Node? Node has been here for a long long time (since 2009! Node is older than *some* of you bunch), it's the most widely used, arguably the most stable, and has the most resources out there for you to learn with. Of course, you can also use Deno or Bun for your runtime if you know how to, but for now we'll stick to Node.
