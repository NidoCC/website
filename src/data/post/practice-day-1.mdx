## Small "Cheatsheet"

**Function:** use one when you would otherwise copy and paste the same code, or when a chunk of code has a clear job you can name (`getGrade`, `isPrime`).

**Return vs console.log:** use `return` when you need the result later (stored, used in math, passed around). Use `console.log` only to look at something while you're working.

**for loop:** use it when you know how many times to repeat (1 to 30, every item).

**while loop:** use it when you repeat until something happens and don't know how many times (find the secret number).

**if / else if / else:** use it when the code has to choose between options. Check the most specific condition first.

**Template literal:** use it whenever you mix text with variables. It's easier to read than using a `+`.

**Can't remember the syntax?** [Look it up](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference). Nobody memorizes it all, and the thing worth remembering is *which tool fits the job*.

2. How many times does the loop run, and what's the last number?
```ts 
for (let i = 1; i < 5; i++) {
  console.log(i);
}
```

:::spoiler[Reveal answer (CLICK)]
**Answer**: the loop runs 4 times, and the last number is 4.

**Rationale**: `i` starts at 1, then prints 1. Goes to 2, prints 2. Goes to 3, prints 3. Goes to 4, prints 4. Goes to 5, the program notices that when `i` is 5 it stops meeting the condition `i < 5` for the loop to continue, so the loop prints `4` last and hence `4` is our last number. Since the loop went from printing 1 to 4 and everything in between without skipping a number, we can also infer that the loop ran 4 times.
:::

3. What prints for score = 85?

### Level 2

**Your first mission**: write a function with name "fizzBuzz" that accepts a parameter called "n" which is of type `number` and returns a `string`. The function should:
- return "Fizz" if the parameter "n" is divisible by 3
- return "Buzz" if the parameter "n" is divislbe by 5
- return "FizzBuzz" if the parameter "n" is divisible by 3 and 5

Then, create a loop that goes from 1 to 30 (inclusive), printing the result of the function you just wrote when you pass it in the loop's variable.

:::spoiler[Hint 1]
Checking whether a number is divisible by another number is the same as checking whether the division between those two numbers yields a remainder of 0. To check the remainder between two numbers in TypeScript/JavaScript, we can use the [modulo operator](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Remainder), like so:

```ts
// getting the remainder of a division
console.log(12 % 5); // -> output: 2
console.log(140971972 % 2); // -> output 0

// checking if a number is divisible by another
console.log(12 % 5 === 0); // -> output: false
console.log(140971972 % 2 === 0); // -> output: true

let n = 32;
console.log(n % 2 === 0); // -> output: true
```
:::

:::spoiler[Hint 2]
Inside of your function, you should put an if statement where the first branch checks if "n" is divisible by 3 AND 5 and where the last branch is an `else` statement that returns `n` wrapped in a [template literal](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Template_literals).
:::

**Math-related challenge (optional)**: can you find a way to check whether `n` is divisible by 3 and 5 simultaneously or not WITHOUT using the AND logical operator (`&&`) in a single expression?

:::spoiler[Challenge Answer]
`n % 3 == 0 && n % 5 == 0` can be rewritten as `n % 15 === 0`.

If it can be divided by 3 and be divided by 5, then it can be divided by the least common multiple of 3 and 5 (which is 15).
:::

Aaaaand here's the answer:

:::spoiler[Answer]
```ts
function fizzBuzz(n: number): string {
  if (n % 15 === 0) {
    return "FizzBuzz";
  } else if (n % 3 === 0) {
    return "Fizz";
  } else if (n % 5 === 0) {
    return "Buzz";
  } else {
    return `${n}`;
  }
}

for (let i = 1; i <= 30; i++) {
  console.log(fizzBuzz(i));
}
```

- `.includes(str)` - returns a boolean based on whether the string contains another string `str`
- `.charAt(index)` - returns a character (a string of length 1) at the `index` position of the string - e.g.: in the string `Hello`, `index` at 0 will give you `H` and index at 4 will give you `o`

:::spoiler[Hint 4]

```ts
if ("aeiou".includes(word.charAt(index).toLowerCase())) {
```

Aaaaand here's the answer:

:::spoiler[Answer]
```ts
function countVowels(word: string): number {
  let count = 0;
  for (let i = 0; i < word.length; i++) {
    if ("aeiou".includes(word.charAt(i).toLowerCase())) {
      count++;
    }
  }
  return count;
}

console.log(countVowels("Programming")); // 3
```

**Your first mission**: write a function with name "isPrime" that accepts a parameter named "n" of type `number` and returns a `boolean`. The function should, given a number "n", return `true` if it is a prime number, or `false` if it is not. Then, create a for loop that prints every **prime** number from 1 (inclusive) to 50 (inclusive).

:::spoiler[Reminder]
If you've forgotten, a prime number is considered to be any number than can ONLY be divided by 1 and itself.

This means that if there's any number between 2 (inclusive) and that number (non-inclusive) that can divide that number, then it is not prime. *How would you implement this in code?*
:::

:::spoiler[Hint 1]
If the number passed into "isPrime" is less than 2, we can automatically discard the number as not prime.
:::

:::spoiler[Hint 2]
If we want to check every number from 2 (inclusive) up to the number itself and whether those numbers in between can divide our number, we can use a for loop that starts at 2, and goes up to our number. Inside this loop, we can use the [modulo operator](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Remainder) to check whether the number we're currently checking can divide our number without leaving a remainder.
:::

:::spoiler[Hint 3]
Inside the loop that checks if the current number we're checking can divide our number "n", return `false` if there is a number that can divide our number: this would mean that a number can divide it that's not itself or 1, hence making it not prime, which is why we return `false`. Do not add an else with a `return true` to the if statement, however; that would make the loop stop the function returning `true` if the first number it checks cannot divide "n".

After the loop, place the `return true`. This means the loop has finalized without returning the function, meaning that no numbers between 1 and itself can divide it, making it prime.
:::

Aaaaand here's the answer:

:::spoiler[Answer]
```ts
function isPrime(n: number): boolean {
  if (n < 2) {
    return false;
  }
  for (let i = 2; i < n; i++) {
    if (n % i === 0) {
      return false;
    }
  }
  return true;
}

for (let n = 1; n <= 50; n++) {
  if (isPrime(n)) {
    console.log(n);
  }
}
```
:::

**Your third (and last) mission**: write two functions. One function should be named "reverse" and accept a string named "text" as argument - the function itself should return a string. The other function should be named "isPalindrome" and accept a string named "word" as argument - the function itself should return a boolean. The "reverse" function should return a reversed version of the string that's passed into it, for example: `reverse("Hello")` should return `"olleH"`. The "isPalindrome" function should check whether the word passed into it is a palindrome or not, and return a `boolean` accordingly.

:::spoiler[Reminder]
A [palindrome](https://en.wikipedia.org/wiki/Palindrome) is a word, phrase, or any other sequence of symbols that reads the same forwards and backwards. Examples of a palindrome:
- "racecar"
- "madam"
- "A man, a plan, a canal – Panama", although this one requires ignoring the punctuating and spacing. We will assume all inputs coming to our "isPalindrome" function is free of whitespace and punctuations.
:::

:::spoiler[Hint 1]
In order to implement the "reverse" function, you need to have an empty string prepared to put the new reversed characters in, one by one.

*How can one add to the empty string letters from the original string but from right to left?*

You'll need the following string methods/properties:
- `.length` - gets the length of a string
- `.charAt(index)` - gets the character from the string at the given index
:::

:::spoiler[Hint 2]
To reverse through a string and add its last character first and first character last to a new string called "result", we can do the following:

```ts
let result = "";
for (let i = text.length - 1; i >= 0; i--) {
  result += text.charAt(i);
}

Before straight up pasting this code in, try to understand it first: *why do we need to subtract 1 from `text.length`? Why do we need `i--` instead of `i++`? What is this code doing?*
```
:::

Aaaaand here's the answer:

:::spoiler[Answer]
```ts
function reverse(text: string): string {
  let result = "";
  for (let i = text.length - 1; i >= 0; i--) {
    result += text.charAt(i);
  }
  return result;
}

function isPalindrome(word: string): boolean {
  return word.toLowerCase() === reverse(word.toLowerCase());
}
```
:::
