Head over to https://code.visualstudio.com/ and download for your platform. Visual Studio Code (or VSCode for short) is available for all major platforms.

This is a good video resource in case you've never used Visual Studio Code or any kind of code editor before: https://www.youtube.com/watch?v=ORrELERGIHs. Feel free to either skim through it or watch it fully depending on how familiar you already were with VSCode. If fully familiar (as in you work with it almost daily), don't be afraid to skip the video.

Here are some extensions that I recommend you to download:

- Better Comments (by Aaron Bond)
- Color Highlight (by Sergii N)
- Error Lens (by Alexander)
- Prettier - Code formatter (by Prettier)
- svelte (by 1YiB) (extension pack)

They are not compulsory but they make your developing experience just a little bit better.
